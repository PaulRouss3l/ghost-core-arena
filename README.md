# Ghost Core Arena

*Work in progress, for Starsector 0.98a.*

## Install

1. Download the zip from the [Releases](https://github.com/PaulRouss3l/ghost-core-arena/releases) page.
2. Extract it into `Starsector/mods/` (you get `mods/ghost-core-arena/`).
3. Enable **Ghost Core Arena** in the launcher.

## Reporting bugs

Please attach your `starsector.log`; the mod's lines start with `[GhostCoreArena]`.
